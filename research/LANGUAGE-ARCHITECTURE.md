# Curtea de Argeș — Language Architecture

## Decision

The public archive is **English-first** for international accessibility. Romanian remains a first-class source and archive language.

This does not replace Romanian research. It creates a controlled international presentation layer over the same historical foundation.

## Canonical model

Each historical object should eventually have one language-independent canonical record:

**record → evidence → source → original language → translation(s)**

The same record may be presented in English, Romanian and later additional languages.

## Rules

1. English is the default public website language.
2. Romanian source titles and quotations are preserved where source fidelity requires them.
3. Canonical modern project naming remains **Curtea de Argeș**.
4. Historical/source spellings may be retained as variants only when representing source metadata or historical usage.
5. Translation must preserve evidence status: VERIFIED, SUPPORTED, DISPUTED, TRADITION, UNKNOWN.
6. Approximate dates must remain approximate after translation.
7. A translation is not a new source and cannot silently replace the original.
8. Browser translation is a convenience only, not the authoritative multilingual archive layer.
9. Additional languages will use the same canonical records rather than separate databases.
10. Every translation layer must be auditable back to the canonical record and original source.

## Public website rebuild

The original Romanian prototype is preserved through a rollback backup. The live public baseline is now being rebuilt as English-first while the research foundation continues unchanged.

The archive should eventually allow a reader anywhere in the world to understand Curtea de Argeș without disconnecting the reader from the Romanian documentary and scholarly record that makes the history verifiable.
